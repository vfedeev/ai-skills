# Adv Checkup — Проверка рекламных макетов

## Назначение
Быстрая проверка рекламных макетов на соответствие законодательству РФ. Минимальная сводка: **Нарушение → Как исправить**.

## Workflow

### 1. Получение макета
Пользователь присылает изображение (фото, скриншот, PDF). Используй `vision_analyze` для чтения содержимого.

### 2. Анализ через vision_analyze
Задай вопрос:
```
Прочитай ВСЕ текстовые элементы на этом рекламном макете. 
Перечисли:
- Все надписи и тексты (включая мелкие)
- Логотипы и товарные знаки
- Возрастные маркировки (если есть)
- Условия акций/подарков
- Упоминания алкоголя, табака, лекарств
- Язык текстов (русский/иностранный)
```

### 3. Сверка с базой законов

**ВАЖНО:** Если макет из отрасли, которой нет в таблице ниже (финансы, табак, продукты, лотереи и т.д.) — **сначала** найди фактические данные в сети:

1. Поищи в web_search: `"статья 38-ФЗ" реклама [отрасль]`
2. Извлеки релевантные статьи и нормы
3. Создай файл `references/38-fz-articleXX-[отрасль].md` с найденными данными
4. Обнови таблицу в SKILL.md
5. **Потом** анализируй сам макет

Не анализируй макет "на глаз" без правовой базы — это грозит ошибочными выводами.

Загрузи нужные references в зависимости от типа макета:

| Тип макета | Какие статьи проверять |
|------------|----------------------|
| Любой | `38-fz-article5.md` (общие требования) |
| Алкоголь | `38-fz-article21.md` (реклама алкоголя) |
| Медицина/лекарства/БАД | `38-fz-article24.md` + `38-fz-article25.md` |
| Косметология/пластическая хирургия | `cosmetology-advertising.md` + `38-fz-article24.md` |
| Недвижимость/долевое строительство | `38-fz-article28-real-estate.md` |
| Мероприятие/кино | `436-fz-article12.md` (возрастная маркировка) |
| Иностранногоязычный текст | `53-fz-article3.md` (государственный язык) |
| Акции/подарки/конкурсы | `38-fz-article5.md` ч. 3 п. 15 (достоверность условий) |
| Логотип/бренд | `rospatent-trademarks.md` (проверка регистрации ТЗ) |

### 3.1. Проверка товарного знака (если есть логотип/бренд)

Если в макете есть логотип, название бренда или фирменное обозначение — **обязательно** проверь регистрацию онлайн:

1. Найди название бренда в макете (латиница/кириллица)
2. Поищи в web_search: `"[название]" товарный знак регистрация Роспатент`
3. Если нашёл информацию о регистрации — укажи номер и статус в сводке
4. Если не нашёл или сомневаешься — укажи "ТЗ не найден в открытых источниках, рекомендуется проверка на searchplatform.rospatent.gov.ru"
5. Если ТЗ зарегистрирован — нарушения по п. 5 ст. 1484 ГК РФ НЕТ, снять этот пункт

## ⚠️ Контроль качества вывода

**ПЕРЕД отправкой ответа ОБЯЗАТЕЛЬНО проверь:**

### 1. Иероглифы (unicode-сканирование)
Пройдись по ВСЕМУ тексту ответа и найди любые китайские/иероглифические символы:
- Диапазон `\u4e00–\u9fff` (CJK Unified Ideographs)
- Диапазон `\u3400–\u4dbf` (CJK Extension A)
- Диапазон `\uf900–\ufaff` (CJK Compatibility)

Если нашёл — **УДАЛИ** их и замени на осмысленный русский текст (артефакт копипаста).

### 2. Точность ссылок на закон
- Все статьи закона указаны **конкретно** (не «по закону», а «ч. 3 ст. 21 38-ФЗ»)
- Номера статей совпадают с текстом нарушения (не путать ст. 24 и ст. 25)
- Даты и номера ФЗ корректны (38-ФЗ от 13.03.2006, 436-ФЗ от 29.12.2010, 53-ФЗ от 01.06.2005)

### 3. Фактическая достоверность
- Не придумывай нормы, которых нет в references/ — если сомневаешься, скажи «требуется уточнение»
- Не смешивай требования для разных типов продукции (лекарства ≠ БАД ≠ косметология)
- Проверь, что рекомендации по исправлению реально устраняют нарушение, а не формальны

### 4. Формат
- Соответствует ли формат шаблону выше (таблица нарушений, чек-лист, рекомендации)
- Нет ли дублирования информации
- Нет ли противоречий между разделами

## Чек-лист быстрой проверки

### Для ЛЮБОГО макета:
- [ ] Текст на русском языке (или есть перевод)
- [ ] Нет некорректных сравнений с конкурентами
- [ ] Нет недостоверных сведений о товаре
- [ ] Указаны существенные условия (цена, сроки, ограничения)
- [ ] Нет порнографии, насилия, нецензурной лексики
- [ ] Нет обращения к несовершеннолетним (для алкоголя/табака)

### Для алкоголя:
- [ ] Нет образов людей/животных
- [ ] Нет утверждений о пользе для здоровья
- [ ] Есть предупреждение о вреде (≥10% площади)
- [ ] Нет обращения к несовершеннолетним
- [ ] Размещение в разрешённых местах

### Для акций/подарков:
- [ ] Указаны точные условия участия
- [ ] Указаны сроки проведения
- [ ] Указано количество призов (если ограничено)
- [ ] Указан порядок получения призов
- [ ] Формулировка соответствует фактическим условиям

### Для мероприятий:
- [ ] Есть возрастная маркировка (0+/6+/12+/16+/18+)
- [ ] Размер маркировки ≥5% площади (для экранов/афиш)
- [ ] Указана категория мероприятия

### Для медицины/лекарств/БАД:
- [ ] Нет ссылок на конкретные случаи излечения
- [ ] Нет благодарностей от "пациентов"
- [ ] Нет гарантий обещанной безопасности отсутствия побочных эффектов
- [ ] Нет впечатления ненужности обращения к врачу
- [ ] Есть предупреждение о противопоказаниях (≥5% площади)
- [ ] Для БАД: есть предупреждение "не является лекарством" (≥10% площади)
- [ ] Для рецептурных средств: размещение ТОЛЬКО в профессиональных изданиях

### Для косметологии:
- [ ] Определить: медицинская услуга (нужна лицензия) или бытовая
- [ ] Для медицинских: все запреты ст. 24 38-ФЗ (гарантии, благодарности, etc.)
- [ ] Есть предупреждение о противопоказаниях (≥5% площади)
- [ ] Нет обращения к несовершеннолетним
- [ ] Нет гарантий обещанной безопасности отсутствия побочных эффектов

### Для недвижимости (долевое строительство):
- [ ] ⚠️ Есть разрешение на строительство (реклама до разрешения ЗАПРЕЩЕНА — ч. 8 ст. 28)
- [ ] Указан адрес сайта единой информационной системы жилищного строительства
- [ ] Указано наименование/фирменное наименование застройщика
- [ ] Указано наименование жилого комплекса (если есть в проектной декларации)
- [ ] Есть гос. регистрация права на земельный участок
- [ ] Нет гарантий сроков строительства/приобретения

## Принцип полноты проверки

При проверке макетов — **делай всё до конца**, а не просто рекомендуй:
- Товарный знак → **проверяй онлайн** через web_search, а не пиши "рекомендуется проверить"
- Нарушение → **указывай конкретную статью**, а не общие ссылки на закон
- Если не можешь проверить (сайт недоступен) — **ясно говори почему**, а не молчи
