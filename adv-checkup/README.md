# Adv Checkup — Проверка рекламных макетов

Скилл для Hermes Agent: быстрая проверка рекламных макетов на соответствие законодательству РФ.

## Что делает

- **Анализирует** текст и элементы рекламного макета (баннер, афиша, баннер, визитка)
- **Сверяет** с нормами 38-ФЗ «О рекламе», 436-ФЗ о защите детей, 53-ФЗ о государственном языке
- **Проверяет** регистрацию товарного знака через базу Роспатент
- **Выдаёт** сводку: Нарушение → Как исправить

### Поддерживаемые отрасли

| Отрасль | Статьи закона |
|---------|---------------|
| Любая реклама | ст. 5 38-ФЗ (общие требования) |
| Алкоголь | ст. 21 38-ФЗ |
| Медицина / лекарства | ст. 24 38-ФЗ |
| БАД | ст. 25 38-ФЗ |
| Косметология | ст. 24 + отраслевые разъяснения |
| Недвижимость (долевое строительство) | ст. 28 38-ФЗ |
| Мероприятия / кино | ст. 12 436-ФЗ (возрастная маркировка) |
| Иностранный текст в рекламе | ст. 3 53-ФЗ |
| Товарные знаки | проверка через searchplatform.rospatent.gov.ru |

## Установка

### Вариант 1: Ручная установка

```bash
# Склонируйте репозиторий
git clone https://github.com/vfedeev/ai-skills.git
cd ai-skills

# Скопируйте скилл в директорию Hermes
cp -r adv-checkup ~/.hermes/skills/
```

### Вариант 2: Из ZIP-архива

```bash
# Скачайте ZIP с GitHub
curl -L -o adv-checkup.zip https://github.com/vfedeev/ai-skills/archive/refs/heads/main.zip

# Распакуйте
unzip adv-checkup.zip

# Установите
cp -r ai-skills-main/adv-checkup ~/.hermes/skills/
```

### Вариант 3: Через Hermes (если поддерживается)

```bash
hermes skill install vfedeev/ai-skills/adv-checkup
```

## Использование

1. Пришлите Hermes изображение рекламного макета
2. Скажите: «Проверь макет», «Есть ли нарушения?», «Можно ли публиковать?»
3. Hermes загрузит скилл, проанализирует макет и выдаст сводку

### Пример вывода

```
🔍 Результат проверки макета

Макет: Баннер «Скидки до 50%» для экрана на остановке
Дата проверки: 2026-08-27

🚨 Найденные нарушения

| # | Нарушение                        | Статья закона    | Как исправить                    |
|---|----------------------------------|------------------|----------------------------------|
| 1 | Нет предупреждения о вреде алкоголя | ч. 3 ст. 21 38-ФЗ | Добавить «Чрезмерное потребление вредит здоровью» ≥10% площади |
```

## Требования

- Hermes Agent с подключённым `vision_analyze` (для чтения макетов)
- Доступ к интернету (для проверки товарных знаков через Роспатент)
