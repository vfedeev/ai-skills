# AI-Transcribe: Транскрибация аудио/видео

## Первый запуск

При первом запуске **ОБЯЗАТЕЛЬНО** выполнить скрипт предконфигурации:
```bash
python3 <install-path>/ai-transcribe/scripts/setup.py
```

Скрипт проверит и настроит:
- API-ключ (Groq/OpenAI)
- ffmpeg / ffprobe
- Python requests
- Имя и роль интервьюера
- Модель STT
- Временную директорию

Конфиг сохраняется в `<install-path>/ai-transcribe/config.env`.

## Входные данные

- Файл: аудио или видео (путь или URL)
- Имена собеседников (спрашивать если не указаны в config)

**Интервьюер** — имя и роль определяются в config.env (настраиваются при первом запуске setup.py).

## Workflow

### 1. Подготовка

**Загрузить config:**
```bash
# source config.env (путь определяется агентом)
# источник: <install-path>/ai-transcribe/config.env
```

**Если видео и HAS_FFMPEG=true** — извлечь аудио:
```bash
ffmpeg -i video.mp4 -vn -ar 16000 -ac 1 "$TEMP_DIR/audio_whisper.wav"
```

**Если видео и HAS_FFMPEG=false** — ошибка: нет ffmpeg, видео не обработать.

**Если аудио** — использовать как есть.

**Проверить длительность (если HAS_FFPROBE=true):**
```bash
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 "$TEMP_DIR/audio_whisper.wav"
```

**Разбиение на чанки:**
- Если длительность > порога STT-модели или > 25 МБ — разбивать
- Пороги уточнить после первого успешного запуска и записать в config.env
- Разбиение по паузам (тишине):
```bash
ffmpeg -i "$TEMP_DIR/audio_whisper.wav" -af silencedetect=n=-30dB:d=0.5 -f null - 2>&1 | grep silence_end
```
- Fallback: по 10 минут с оверлапом ±30 сек, дубли убрать при склейке

Имена собеседников определяются из config.env.

### 2. Транскрибация

**Groq API:**
```python
import requests, os

def transcribe(file_path):
    api_key = os.environ.get("GROQ_API_KEY")
    url = API_URL  # из config.env
    model = STT_MODEL  # из config.env
    headers = {"Authorization": f"Bearer {api_key}"}
    with open(file_path, "rb") as f:
        resp = requests.post(url, headers=headers,
            files={"file": f},
            data={"model": model})
    return resp.json()["text"]
```

**Определение языка:**
- Не хардкодить. Если модель поддерживает `language` параметр — определить по контексту или спросить.

### 3. Постобработка

1. **Склеить чанки** — объединить в хронологическом порядке, убрать дубли на стыках
2. **Очистка от иероглифов** — удалить U+4E00–U+9FFF, U+3040–U+30FF, U+31F0–U+31FF (мусор от китайских моделей)
3. **Проверка ошибок** — исправить опечатки транскрибации, НЕ править разговорную речь
4. **Разделение по спикерам** — по контексту и именам из config.env

### 4. Формат вывода

```markdown
# Транскрибация — [Название/Дата]

**Участники:** [Имя1] (роль), [Имя2] (роль)

---

**[Имя1]:** Текст реплики.

**[Имя2]:** Текст реплики.

---

## Краткое содержание
- Тезис 1
- Тезис 2
```

### 5. Показать пользователю

Вывести в чат. Пользователь проверяет.

### 6. Сохранение и очистка

**Сохранить:**
- Транскрибацию в указанный путь
- Оригинал (НЕ удалять)

**Удалить:**
- `"$TEMP_DIR/audio_whisper.wav"`
- `"$TEMP_DIR/chunk_*.wav"`

**Спросить:**
- Тезисы из разговора?
- ТЗ на дизайн?
- Удалить временные файлы? (по умолчанию — да)

**Итого на диске:**
- Оригинальный источник
- Результаты (транскрибация + тезисы/ТЗ если запрашивались)

## Примеры запросов

- «транскрибируй это аудио» + файл
- «расшифруй запись созвона» + файл
- «что обсуждали на встрече» + файл

## Важно

- НЕ выдумывать слова — ставить `[...]`
- НЕ править разговорную речь
- Сохранять оригинальную интонацию
- Проверять что имена соответствуют ролям
