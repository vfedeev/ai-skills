# UltraUI Layers — Разбор сайта по 6 слоям

Метод визуального разбора сайтов по **6 слоям Ultra UI** — набору стилеобразующих приёмов, за счёт которых интерфейс вызывает нужный эмоциональный отклик.

> Источник: [[Дизайн/UX-UI/UltraUI.md]], курсы Апрок (Евгений Кузьмин)

## Алгоритм анализа

### 1. Сбор данных

Два параллельных источника:

```
# HTML-источник — CSS-переменные, шрифты, цвета, структура
curl -sL https://example.com | head -400

# Контентный источник — текст, структура страницы, изображения
web_extract(urls=["https://example.com"], char_limit=20000)
```

**Что искать в HTML:**
- `<style>` блоки — цвета (`background`, `color`), CSS-переменные
- `font-family`, `@font-face` — шрифты
- `text-transform`, `font-weight`, `letter-spacing` — типографические решения
- CSS-классы с `transition`, `animation`, `transform`, `parallax` — анимации
- Grid/Flex структура — композиция
- Blend modes (`mix-blend-*`) — работа с медиа
- `rounded`, `border-radius`, SVG-формы — графика

### 2. Структура ответа

**Сводная таблица — ВЕРХ ответа.** Краткая матрица: какой слой что делает.

Затем — **расшифровки по слоям** (детали, CSS-доказательства, эмоциональный эффект).

### 3. Шесть слоёв Ultra UI

| # | Слой | Что анализируем | Ключевые вопросы |
|---|------|----------------|-----------------|
| 1 | **Типографика** | Шрифты, кегль, начертания, tracking, кейс | Какой характер? Serif/grotesque? Уникальный или стандартный? |
| 2 | **Цвет** | Палитра, насыщенность, контраст, количество цветов | Монохром/двухцвет/полихром? Яркий/сдержанный? |
| 3 | **Анимации** | Переходы, parallax, scroll-эффекты, microinteractions | Много/мало? Кастомные или дефолтные? Какой темп? |
| 4 | **Сетка и композиция** | Сетка, отступы, whitespace, баланс, плотность | Много воздуха или плотно? Симметрия/асимметрия? |
| 5 | **Графика и формы** | Иконки, декор, геометрия, текстуры, паттерны | Острые/скруглённые? Плоские/объёмные? Узнаваемый язык? |
| 6 | **Медиаконтент** | Фото, видео, иллюстрации, blend modes | Обработаны/сырые? Какую эмоцию несут? |

### 5. Классификация ролей

- **⭐ Ведущий** — активно формирует стиль, выделяется, несёт основную эмоциональную нагрузку
- **🔸 Поддерживающий** — работает на функциональность, не привлекает к себе внимания, «правильный дефолт»

## ⚠️ Контроль качества вывода

**ПЕРЕД отправкой ответа ОБЯЗАТЕЛЬНО проверь:**

### 1. Иероглифы (unicode-сканирование)
Пройдись по ВСЕМУ тексту ответа и найди любые китайские/иероглифические символы:
- Диапазон `\u4e00–\u9fff` (CJK Unified Ideographs)
- Диапазон `\u3400–\u4dbf` (CJK Extension A)
- Диапазон `\uf900–\ufaff` (CJK Compatibility)

Если нашёл — **УДАЛИ** их и замени на осмысленный русский/английский текст (артефакт копипаста).

### 2. Точность данных
- Все HEX-коды цветов должны быть извлечены из CSS/HTML, а не придуманы
- Размеры шрифтов и отступов — только из CSS или честная оценка с пометкой «оценка»
- CSS-классы и свойства — только если реально найдены в исходниках

### 3. Фактическая достоверность
- Не выдумывай анимации, которых нет — если CSS недоступен, пиши «извлечено из структуры»
- Не путай типы страниц (главная vs лендинг vs магазин)
- Инференсы (эмоциональное ядро) — всегда помечай как вывод, не как факт

### 4. Формат
- Сводная таблица — в верху ответа
- Все 6 слоёв присутствуют
- Каждый слой имеет: таблицу параметров → Эфект → Резюме
- Нет дублирования информации между слоями

## Анти-паттерны

- **Не выдумывать** то, что невозможно подтвердить из HTML/контента. Если CSS недоступен — честно писать «извлечено из структуры»
- **Не путать** «главную страницу» с «лендингом» — уточнять тип страницы
- **Отмечать инференсы** от данных: «эмоциональное ядро» — всегда инференс, не факт
- **Сравнивать** с другими разборами — если уже есть референс, использовать как точку отсчёта
- **Нет иероглифов** — ответ только на русском/английском. Никаких CJK-символов, китайских иероглифов или мусорных unicode-блоков. Если в исходном HTML есть не-латинские символы — транслитерируй или опиши словами

## Примеры разборов

### hermes-agent.nousresearch.com

**Тип:** лендинг десктопного AI-продукта (open-source, MIT)
**Эмоциональное ядро** (инференс): технологическое превосходство, растущая мощь, эстетика хакера-одиночки, превращённая в премиальный продукт.

| Слой | Роль | Эмоция |
|------|------|--------|
| Типографика | ⭐ Ведущий | Монументальность, архитектурная строгость |
| Цвет | ⭐ Ведущий | Электрическая глубина, синий как «бесконечность кода» |
| Анимации | ⭐ Ведущий | Параллакс-погружение, кинематографический темп |
| Сетка/композиция | 🔸 Поддерживающий | Асимметричный воздух, масштабный фрейм |
| Графика/формы | 🔸 Поддерживающий | Мягкие формы, glow-свечения |
| Медиа | ⭐ Ведущий | Витринное видео + альфа-оверлеи + blend-слои |

**Вердикт:** Медиа, типографика и цвет — три равноценных ведущих слоя. Каждая секция — отдельный кадр. Сравнимо с Linear или Arc, но агрессивнее.

**Типографика:** Sigurd (serif, variable) — hero ~132px, feature ~64px, body ~21px. Courier Prime (mono) для UI. Глобальный uppercase, line-height hero 0.88. Контраст кеглей ~6:1.

**Цвет:** `#0000f2` (deep blue, фон) + `#f5f5f5` (текст). Двухцветная палитра, монохромная доминанта. Белые кнопки с тенью.

**Анимации:** Кастомные: `hw-parallax`, `mix-blend-lighten/screen`, `hw-vignette`, `hw-noise`, `hw-feature-parallax`, ghost-wordmark, альфа-видео в футере. Полностью кастомные, ни одна не дефолтная.

**Сетка:** CSS Grid + container queries. `max-w-[1600px]`. Fluid-unit `--u` через container width. Breakpoint: 767px (бинарный). Щедрый whitespace.

**Графика:** Soft-glow стиль, размытые края, без жёстких контуров. Hero-art, platform-art, feature-иллюстрации — все в едином стиле «электрический туман».

**Медиа:** 12+ изображений. Hero-art.webp (mix-blend-lighten), mp4-демо, 6 feature images с parallax + blend, альфа-видео portal-figure. Next.js image optimization.

### uprock.ru

**Тип:** лендинг онлайн-школы дизайна (Webflow)
**Эмоциональное ядро** (инференс): профессиональная доступность — «ты сможешь стать дизайнером».

| Слой | Роль | Эмоция |
|------|------|--------|
| Типографика | 🔸 Поддерживающий | Стабильность, читаемость |
| Цвет | 🔸 Поддерживающий | Фокус, доверие, индиго-интонация |
| Анимации | 🔸 Поддерживающий | Лёгкая интерактивность, без шоу |
| Сетка/композиция | 🔸 Поддерживающий | Упорядоченность, стандартная Webflow |
| Графика/формы | ⭐ Ведущий | Узнаваемость бренда |
| Медиа | ⭐ Ведущий | Социальное доказательство, результат |

**Вердикт:** Графика и медиа ведущие, остальные 4 слоя на Webflow-автомате. Выглядит «правильно», но не выделяется.

**Типографика:** [Inter](https://fonts.google.com/specimen/Inter) (sans-serif, 300–700). Hero ~40–56px, body ~16–18px, контраст ~3x. Без uppercase, стандартный трекинг. Один шрифт на весь сайт.

**Цвет:** `#3318FF` (индиго, акцент) + `#FFFFFF` (фон) + `#F3F3F3` (вторичный фон) + `#1D1D20` (текст). Двухцветная с нейтральными серыми.

**Анимации:** Webflow-дефолт + Swiper.js. Нет parallax, нет viewport-triggered, нет кастомных microinteractions. Минимальный набор.

**Сетка:** Flex + CSS Grid (микс). `w-container` ~940px. Breakpoints: 479/767/991/1280/1440px. Умеренный whitespace, симметричная композиция.

**Графика:** SVG-иконки line-art на круглых подложках `#F3F3F3`. Единый стиль, узнаваемый, но не уникальный. Скруглённые формы.

**Медиа:** Обложки курсов (avif/webp), аватары экспертов, галерея работ студентов в Swiper. Без видео и анимированных превью.
