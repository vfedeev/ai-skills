# Слои Ultra UI — Детали для аудита

> Источник: [[Дизайн/UX-UI/UltraUI.md]], курсы Апрок (Евгений Кузьмин)

## Контекст метода

Слои Ultra UI — третий этап подготовки к визуальной концепции:
1. Работа с эмоциями и ассоциациями по теме проекта
2. Мудборд (Behance, Pinterest)
3. **Конкретизация стиля через слои Ultra UI**

Задача дизайнера — не просто использовать все параметры, а управлять ими: понимать, какие из них ведущие, а какие сдержанные. Для каждой эмоции проекта прописать, какие слои помогут её передать.

> Одна эмоция может передаваться через несколько слоёв: «уверенность» → крупная типографика + чёткая сетка + сдержанная палитра.

## 6 слоёв — детали

### 1. Типографика
- Выбор шрифтовых пар, начертаний, кегля и межстрочного
- Крупная типографика → уверенность, заявление; тонкие гротески → лёгкость, минимализм
- Контраст размеров задаёт иерархию и характер
- Serif/grotesque — определяет характер (шерифный = традиция, гротеск = современность)
- **Ключевые вопросы:** Какой характер? Уникальный или стандартный? Есть ли контраст кеглей?

### 2. Цвет
- Палитра и её насыщенность/сдержанность
- Тёплые/холодные, яркие/приглушённые сочетания → настроение
- Ограниченная палитра = премиальность и фокус
- **Ключевые вопросы:** Монохром/двухцвет/полихром? Яркий/сдержанный? Контраст?

### 3. Анимации
- Микровзаимодействия, переходы, скролл-эффекты, параллакс
- Плавность и темп формируют ощущение «дорогого» и живого продукта
- **Ключевые вопросы:** Много/мало? Кастомные или дефолтные? Какой темп?

### 4. Сетка и композиция
- Модульная сетка, ритм, отступы, баланс whitespace
- Чёткая сетка → порядок, надёжность; сломанная/асимметричная → динамика, смелость
- **Ключевые вопросы:** Много воздуха или плотно? Симметрия/асимметрия?

### 5. Графика и формы
- Иконки, декор, геометрия (острые/скруглённые), паттерны, текстуры
- Округлые → дружелюбие; острые → технологичность/строгость
- **Ключевые вопросы:** Плоские/объёмные? Узнаваемый язык? Depth?

### 6. Медиаконтент
- Фото, видео, иллюстрации
- Стиль и качество медиа — сильнейший носитель эмоции и атмосферы бренда
- Blend modes, parallax, обработка → усиливают эффект
- **Ключевые вопросы:** Обработаны/сырые? Какую эмоцию несут? Интегрированы с другими слоями?

## Алгоритм работы с мудбордом

Из большого массива референсов отбираются ключевые приёмы для каждого слоя (по 3–10 референсов на слой). Фиксируется только то, что передаёт выбранное настроение.

## Связанные темы

- Эмоциональное ядро проекта — база для всех визуальных решений
- Мудборд — связующее звено между эмоциями и конкретными приёмами
- Рейтинг креативности — оценка выразительности решения
