# Design Scaling — от ч/б прототипа к концепции, UI-kit и страницам

Скилл для Claude Code и Hermes Agent: трёхэтапный пайплайн дизайна сайта в Figma. Этап 0 — по функциональному прототипу (ФП) и фрэнки (мудборд из фрагментов чужих сайтов по блокам) создаёт редактируемый чёрно-белый композиционный прототип, а после его согласования — первую Hi-fi-концепцию. Этап А — измеряет утверждённую концепцию и снимает с неё правила дизайна (`дизайн-правила.md`) и UI-kit. Этап Б — собирает макеты остальных страниц строго по правилам и UI-kit; фрэнки задаёт композицию блоков, но не значения.

## Что делает

- **Этап 0**: ищет таблицу эмоциональных/визуальных выводов проекта, разбирает фрэнки на фрагменты, согласовывает композицию текстом до сборки, создаёт ч/б прототип в текущем Figma-файле (обычные редактируемые слои, БЭМ-имена), отдаёт его пользователю на самостоятельные правки, затем разрабатывает Hi-fi-концепцию
- **Этап А**: инвентаризация концепции (`inventory.js`), цветовые роли и привязка каждого цвета к переменной (`bind-colors.js`, `color-audit.js` — работа не закончена, пока `unbound = []`), текстовые стили, компоненты UI-kit, файл правил по шаблону
- **Этап Б**: страница из правил и UI-kit по прототипу и текстам; приёмы фрэнки переводятся на токены (ни один шрифт, цвет или px со скриншута чужого сайта не копируется); изображения — заглушки с промтом внутри
- **QA**: первична программная геометрия (`qa-geometry.js`: границы секций, клипы, переполнение auto-layout, наезды текстов), вторична vision-сверка скриншотов
- **Шрифты**: сценарии «доступны / библиотека + недоступны / недоступны» с заменами из Google Fonts и скриптом `restyle-texts.js`

## Триггеры

«Создай первую концепцию», «у меня нет готовой главной в Figma», «сделай дизайн по ФП и фрэнки», «изучи концепцию», «составь правила / гайдлайн по макету», «собери UI-kit из макета», «сделай дизайн страницы по прототипу», «сверстай страницу по текстам», «сделай страницу по фрэнки», «масштабируй дизайн на другие страницы», «привяжи цвета к переменным».

## Комплект

| Файл | Назначение |
|------|-----------|
| `SKILL.md` | три этапа, маршрутизация «задача → что читать», отчётность, частые ошибки |
| `references/stage-0.md` | этап 0: ч/б прототип → Hi-fi-концепция (порядок, чек-пойнты, таблица выводов) |
| `references/stage-a.md` | этап А: измерение концепции → правила + UI-kit |
| `references/stage-b.md` | этап Б: сборка страницы по правилам и UI-kit |
| `references/frankie.md` | как читать фрэнки: фрагмент → приём → перевод на токены |
| `references/frankie-base.md` | слой ДО фрэнки: база референсов, теги block_type, сборка страницы Frankenstein |
| `references/refs-sources.md` | источники референсов: живые/мёртвые API, gallery-dl, локальная CLIP-семантика |
| `references/sketch.md` | вход — фото рукописного скетча: протокол → сборка |
| `references/colors.md` | цветовые роли, привязка к переменным, концепция на внешней библиотеке |
| `references/hermes-env.md` | среда Hermes: маппинг инструментов figma-console-cloud, пейринг, QA |
| `assets/rules-template.md` | шаблон файла `дизайн-правила.md` |
| `scripts/inventory.js` | инвентаризация макета: частоты стилей, цветов, отступов, радиусов |
| `scripts/color-audit.js` | аудит цветов: сколько привязано к переменным, сколько нет |
| `scripts/bind-colors.js` | привязка цветов к ролевым переменным |
| `scripts/restyle-texts.js` | пересоздание текстов на доступных шрифтах с привязкой цветов |
| `scripts/detach-library.js` | отвязка от внешней библиотеки, перевод на локальные стили |
| `scripts/inline-photo-gaps.js` | «окно в тексте» + заглушка фото (приём мини-фото внутри строки) |
| `scripts/image-prompt.js` | заглушки с промтами для изображений |
| `scripts/qa-geometry.js` | программный QA геометрии: клипы, переполнения, наезды текстов |

Скрипты — для Figma Plugin API (`use_figma` / `figma_execute`): перед запуском заменить `ROOT_ID` на id целевого узла.

## Требования

- Figma: в Claude Code — коннектор claude.ai Figma с правом редактирования; в Hermes Agent — MCP `figma-console-cloud` (плагин Desktop Bridge в Figma Desktop)
- Скилл `figma-use` (процедуры Plugin API) — загружать перед первым вызовом; в Hermes для UI-kit полезен также `figma-generate-library`
- Для нарезки фрагментов и thumbnail в Hermes: Python 3 + Pillow

## Установка

### Через git

```bash
git clone https://github.com/vfedeev/ai-skills.git
cd ai-skills
cp -r design-scaling ~/.hermes/skills/   # или ~/.claude/skills/ для Claude Code
```

### Из ZIP-архива

```bash
curl -L -o ai-skills.zip https://github.com/vfedeev/ai-skills/releases/latest/download/ai-skills-v3.7.0.zip
unzip ai-skills.zip
cp -r ai-skills-v3.7.0/design-scaling ~/.hermes/skills/
```

## Быстрый старт

1. Этап 0: «Создай первую дизайн-концепцию по ФП и фрэнки» + материалы (прототип, фрэнки, тексты, бриф). Сначала получите ч/б прототип для самостоятельных правок, после подтверждения — Hi-fi-концепцию.
2. Этап А: «Изучи концепцию и собери правила и UI-kit» + ссылка на фрейм утверждённой концепции.
3. Этап Б: «Сделай дизайн страницы по прототипу» + ссылки на прототип, тексты и (если есть) фрэнки страницы.
