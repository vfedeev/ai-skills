# Competitor Analysis Deep

Глубокий конкурентный анализ: сбор данных из брифа + веб-исследование, скриншоты в 3 вьюпортах (десктоп/планшет/смартфон), заполнение таблицы по шаблону Апрок, факт-чек.

## Что делает

Multi-agent пайплайн из 4 ролей:

| Роль | Задача |
|------|--------|
| **Директор** | Оркестрация, сбор отчётов, заполнение таблицы, итоговые выводы |
| **Веб-парсер** (×N) | По 1 на конкурента: обходит страницы, собирает данные через web_search + web_extract |
| **Фотограф** | Скриншоты всех конкурентов в 3 вьюпортах через Playwright, упаковка в ZIP |
| **Критик** | Проверка отчётов на галлюцинации, факт-чек, замена иероглифов |

## Workflow

1. Директор получает бриф, извлекает конкурентов
2. Пользователь выбирает страницы и модели через clarify
3. Параллельно: Веб-парсеры собирают данные + Фотограф делает скриншоты
4. Критик проверяет каждый отчёт (макс. 3 круга доработки)
5. Директор заполняет таблицу, неподтверждённые данные помечает «требует проверки»
6. Итог: таблица + архив скриншотов

## Шаблон таблицы

5 секций, 35 вопросов:

1. **Общее** (19) — продукт, УТП, позиционирование, доверие, компетенция, системные страницы, микросервисы
2. **Опыт пользователя** (9) — состав страниц, удобство, навигация, формы, эстетика, анимация, цвет, ассоциации
3. **Повествование / Контент** (4) — эффективность, читаемость, конкретность, ошибки
4. **Техническая сторона** (4) — загрузка, адаптив, ошибки, битые ссылки
5. **Маркетинг** (4) — лояльность, цены, гарантии, качество

Колонки: Вопрос | Конкурент 1 | ... | Конкурент N | Выводы

## Скриншоты

3 вьюпорта через Playwright (headless Chromium):

| Устройство | Ширина | Высота | DPR |
|-----------|--------|--------|-----|
| Desktop | 1920 | 1080 | 1 |
| Tablet | 768 | 1024 | 2 |
| Smartphone | 375 | 812 | 2 |

Имена: `{domain}--{page_name}--{viewport}.png`

## Требования

- Hermes Agent с `delegate_task`, `web_search`, `web_extract`, `clarify`
- Playwright + Chromium (headless) — см. `references/setup.md`
- SearXNG (опционально, для факт-чека)
- Провайдер LLM для субагентов (выбирается через clarify)
