# Search & Analyze — глубокое исследование с фактчек-гейтом

Скилл для Hermes Agent: многоисточниковое исследование «проведи поиск / сравни X и Y / кто лидер рынка / проверь факты» — с планированием, параллельным сбором через субагентов и **блокирующим гейтом фактчека** перед отчётом. Итог — Markdown-отчёт с таблицами источников и уверенности, где ни один непроверенный факт не проходит как достоверный и ни одна неудача проверки не исчезает молча.

## Что делает

- **Планирование**: декомпозиция по оси запроса пользователя (состав vs степень — не подменять), 3–7 независимых подзадач, волны; выбор «один агент против fan-out» по формуле контекстного окна; до первой генерации замораживаются task contract и рубрика приёмки (правка рубрики после просмотра кандидатов = новый эксперимент со перескором всех).
- **Сбор**: batch `delegate_task` — параллельные дети-сборщики с анти-галлюцинационным контрактом (данные только из инструментов, каждое утверждение со ссылкой, «не найдено» вместо домысливания), watchdog каждые ~3 минуты с докладом о причине зависания, логи промптов на диск, loop-until-dry (стоп после 2 пустых раундов, множество «seen» включает отвергнутые).
- **Агрегация**: аудит файлов детей (модельные артефакты, целостность цитат), дедуп URL, метки relevance/needs_check, каждый нагружающий вывод заводится в **claims-ledger** (JSON-шаблон в `templates/`).
- **⛔ Факт-чек-гейт (hard gate)**: вторая adversarial-волна — верификаторы, которым дают claim+источники БЕЗ аргументации сборщика; CONFIRMED только по воспроизводимому check (re-fetch/grep/evidence-файл), majority vote ≠ проверка; три статуса CONFIRMED/REFUTED/UNKNOWN + proof log; judge panel до сходимости оценок; конфликты источников — хронологией; 3 провала на claim → data_gap; при неустранимой неопределённости — прямой вопрос пользователю.
- **Отчёт**: executive summary, секции по подвопросам, таблицы источников/уверенности (выгрузка ledger), вердикт, data gaps, честная стоимость прогона в футере. Сохранение в .md; доставка в заметку Obsidian — по запросу.

Отдельные методики (все в `references/`, открываются по ситуации): фактчек персоны/интервью (8 правил атрибуции реплик, «самозаявление ≠ факт»), восстановление при блокировке YouTube-транскриптов (429-цепочка yt-dlp), проверка дословных цитат (скрипт), геосторы приложений через API, GitHub-лицензии, обход bot-wall, майнинг документации (`llms.txt`, `.md`-суффиксы, raw-репо), контент-фильтры подписочных Qwen-провайдеров при делегировании.

## Требования

- Hermes Agent с работающим `delegate_task` (для режима fan-out; solo-режим работает и без делегирования)
- Python 3.8+ (stdlib) — для `scripts/fetch_quote.py`
- Опционально: `yt-dlp` (фактчек видео/соцсетей), ffmpeg

## Установка

```bash
git clone https://github.com/vfedeev/ai-skills.git
cp -r ai-skills/search-analyze ~/.hermes/skills/
```

## Быстрый старт

> «Проведи исследование: сравни X и Y по ценам и бенчмаркам за 2026 год, с фактчеком»

Скилл сам попросит недостающее до fan-out, разложит тему на подзадачи, запустит сборщиков, затем независимую проверку каждого нагружающего факта и вернёт отчёт `.md` + claims-ledger. Для проверки одной цитаты без полного цикла: `python3 scripts/fetch_quote.py "<URL>" "<точная фраза>"`.
