# Дока framework/инструмента как источник (открывать: тема — сайт с документацией/тулинг, а не новости)

- Пробуй `https://<docs-domain>/llms.txt` и `/_llms/docs.txt` — Mintlify-style сайты отдают полный индекс всех страниц (иногда и каталог с сотнями страниц) — идти по нему, а не гуглить наугад.
- К любому URL страницы доки добавляй суффикс `.md` — тот же текст чистым markdown без UI-обрамления и без JS; батчами по ≤5 URL за `web_extract`.
- Внутренности агентских инструментов (скиллы, doctrine, конфиги) чаще всего лежат в открытом репо: листинг через `api.github.com/repos/<owner>/<repo>/contents/<dir>`, содержимое через `raw.githubusercontent.com/<owner>/<repo>/main/<path>` — сырые исходники скиллов богаче опубликованных статей в 3–5 раз (там реальные числа и правила).
- Актуальность инструмента меряй прямо: `npm view <pkg> version dist-tags.latest time.modified` (аналоги: PyPI JSON API). Сравни с версией, на которую сделаны собственные прошлые заметки — расхождение фиксируй в источниках.
- Найденное в доках, противоречащее ранее записанному факту базы, переписывает факт на месте с датой, а не дописывается отдельным блоком.
