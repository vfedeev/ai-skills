# Контракт и шаблон промпта субагента (открывать: Шаг 2, перед формулированием задач)

## Контракт субагента (анти-галлюцинация — обязательно, в контекст каждого ребёнка)

- Субагент собирает данные только инструментами `web_search` / `web_extract` (и профильными: arxiv, blogwatcher, polymarket, youtube-content). **ЗАПРЕЩЕНО выдумывать факты, цифры, цитаты, URL.**
- Каждое утверждение сопровождается реальной ссылкой на извлечённый источник. Собственные выводы/инференсы помечать отдельно и НЕ выдавать за факт.
- Если данных нет — писать «не найдено», а не домысливать под желаемый вывод.
- **Апрувов и паролей не просить:** не выполнять команд, требующих подтверждения (sudo, установки, внешние записи); не дошёл — пометь `data_gap` и верни что есть.
- **Видео/соцсети:** найденные YouTube/видео — через навык `youtube-content` (транскрипция, цитировать по тексту, не по описанию). Закрытые Instagram/TikTok/VK — обходные пути на выбор (приоритет `yt-dlp` для метаданных постов, см. `references/persona-factcheck.md` §Техника). Не помечать факт проверенным, если источник не открылся и не подтверждён иным способом.
- **Файл-контракт:** полный отчёт пишется в явный scratch-путь (mkdir -p указать), в summary — путь + N источников + топ-5 находок; файл = источник истины, summary = карта.
- **Формат выхода:** промпт самодостаточен (ребёнок не знает контекст чата), явный период поиска, явный язык ответа, «верни 5–7 ключевых выводов, не более». Если деливерабл — заметка базы знаний: формат «как для заметки» (H1, секции, сниппеты с URL рядом, '## Источники' с датой доступа и relevance, '## Data gaps' с честными пробелами вместо додумывания).

## Шаблон промпта

```
Goal: [одно предложение — что должно быть в результате]

Context:
- Ищи информацию только в [период, например "2025-2026 годах"]
- Используй web_search и web_extract
- Предпочитай [тип источников: "официальные сайты", "бенчмарки", "документация"]
- Не выдумывай — если данных нет, пометь "unknown"
- [Язык ответа: "Английский" или "Русский"]
- [Фильтр-безопасность для Qwen: «узкие запросы, ≤3 поиска, не открывать длинные списки сайтов целиком» — см. provider-filters.md]
- [Засев: «УЖЕ ПРОВЕРЕНО ОРКЕСТРАТОРОМ: … — не подтверждай повторно»]
- Верни 5–7 ключевых выводов, не более
- Файл-контракт: полный отчёт в явный scratch-путь (mkdir -p указать), в ответ — путь + N источников + топ-5 находок
- НЕ редактируй ledger.json
```
