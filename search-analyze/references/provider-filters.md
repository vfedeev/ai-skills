# Content-фильтры Qwen/alibaba-token-plan (открывать: делегирование на Qwen-провайдере или падение ребёнка по фильтр-ошибке)

Входной фильтр провайдера убивает субагента на NSFW-доменах и широких запросах — молча, посреди батча.

## Профилактика: «безопасный режим» в контекст каждого ребёнка

- узкие кавычковые/`site:`-запросы;
- ≤3 поиска на сервис;
- никогда не открывать целиком файлы-инвентари сайтов (списки доменов, каталоги «всё о X»).

Полный разбор паттерна — pitfall «Provider content filters» в скилле `delegate-task-narrative`.

## Реакция: ребёнок упал по фильтр-ошибке

1. Извлеки нужные ему факты локально: curl в scratch + grep только целевых строк.
2. Перезапусти его с суженой задачей и засей списком «УЖЕ ПРОВЕРЕНО ОРКЕСТРАТОРОМ — не подтверждай, не открывай <источник>».
3. Остальных живых детей сразу предупреди через `steer` о триггере (какой домен/запрос взорвал фильтр).
