# Цепочка восстановления YouTube 429 (открывать: транскрипция не извлекается — HTTP 429 / 403 / blocked)

Навык `youtube-content` (через `youtube-transcript-api`) и даже `yt-dlp --write-subs` часто падают с **HTTP 429 (Too Many Requests)** на IP облачного/VPS-провайдера — YouTube блокирует такие диапазоны для доступа к субтитрам. Это НЕ повод фабриковать содержимое видео. Действуй строго по цепочке (НЕ выдумывать!):

1. **Пауза + повтор с другим player_client.** 429 — это rate-limit: `sleep 30-60` между попытками реально помогает; `yt-dlp --sleep-interval 5 --extractor-args "youtube:player_client=tv_embedded" --write-auto-subs --sub-lang ru --sub-format vtt "URL"` (порядок клиентов: `tv_embedded` → `android` → `ios` → `web`).
2. **Invidious-зеркало:** `yt-dlp --write-auto-subs --sub-lang ru "https://yewtu.be/watch?v=VIDEO_ID"` — независимый фронтенд, часто обходит блок.
3. **Фолбэк на метаданные/описание (обычно выживает под 429).** Сами субтитры блокируются, но endpoint страницы/плейлиста — нет. Первичный контент автора (описание, список видео) цитируй как позицию субъекта (Правило №1: самозаявление ≠ независимый факт):
   ```bash
   yt-dlp --no-warnings --skip-download --print "%(title)s | %(description)s | %(upload_date)s | %(channel)s" "<URL>"
   yt-dlp --no-warnings --flat-playlist --playlist-end 20 --print "%(id)s | %(title)s | %(duration)s" "<CHANNEL>/videos"
   ```
4. **Не прошло?** — НЕ цитируй «должно быть в видео» и НЕ приписывай видео факты. Пометь факт `verified: false / data_gap`, зафиксируй в отчёте «транскрипт заблокирован YouTube (429), использованы описания связанных видео автора + независимые источники», и иди в эскалацию гейта (другие домены, archive.org, аудитория). Это жёсткое требование анти-галлюцинационного контракта.

## Механика 429

IP-репутация дата-центра → rolling rate-limit → бот-детекторы. **Личный VPN пользователя НЕ снимет блок**, т.к. агент крутится на сервере; 429 — оконный лимит, лечится backoff. Подробности: раздел «Rate limiting» в SKILL.md навыка `youtube-content`.

*Причина появления: инцидент тест-прогона канала по Египту (2026-07) — без recovery-цепочки агент оказался бы перед выбором «фантазировать или остановиться».*
