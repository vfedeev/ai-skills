# Шаблон заметки о задаче (references/log/)

Имя файла: `ГГГГ-ММ-ДД-короткая-тема.md` (например `2026-09-21-mehanika-ochistka.md`). Одна задача = одна заметка. Заполнять после сдачи результата, до закрытия задачи.

```markdown
# <тема: какой текст, от какого клиента/проекта>

Дата: ГГГГ-ММ-ДД
Источник: <файл (путь) / вставка в чат>; объём: <строк/знаков>
Результат: <куда сохранён чистовой файл или «в чате»>

## Паттерны, найденные в этом тексте
- <символ/конструкция> → <что сделали> (кол-во вхождений: N)
- ...

## Правила из эталона пользователя
1. <правило одним предложением>
2. ...

## Спорные места и решения пользователя
- <вопрос> → <что ответил пользователь>

## До / после (1 короткий пример)

    ДО:
    <строка-другая из сырого текста>

    ПОСЛЕ:
    <то же исправленное>

## Скрипты
- <путь в workspace или scripts/скилла> — <что делает>
(если правил не было)
```

Ведение:
- Правила, повторяющиеся в 2+ заметках, переносятся в `references/patterns.md` в раздел «Проверенные правила проекта» — там они работают как дефолты при отсутствии эталона.
- Заметки не редактируются задним числом; если решение отменено — новая заметка или допись «UPDATE:» в конце старой.
