# Добавлены пресеты CJK и ТИПО

Дата: 2026-09-21
Источник: синтетические тесты в workspace (CJK-примеси, кавычки/тире/пробелы); боевого входа ещё не было
Результат: `scripts/strip_cjk.py`, `scripts/typo_ru.py`, секция пресетов в SKILL.md

## Что делают пресеты (без эталона)
- CJK: аудит по Unicode-группам → `--map` (полноширинные ，：！（） → обычные, 《》 → «…»), `--remove` (идеографы+кана+хангыль). Mojibake подсвечивается отдельно и НЕ лечится молча.
- ТИПО: `"..."` → «…», вложенные → „…“; ` - `/`--` → ` — `; числовые диапазоны → `–`; `...` → `…`; пробелы перед знаками препинания убраны. Незакрытые кавычки — в отчёт/вопросы, не угадываются. `--attach-short` (НБСП у однобуквенных предлогов) только по просьбе.

## Баги, найденные smoke-тестом (запомнить!)
1. Конкатенация regex-классов `[A][B][C]` = последовательность символов, а не множество —
   SCRIPT_RE молча давал 0 удалений. Группы склеивать через `|`.
2. `(?<=[{W}])`, где W сам `[...]` → вложенный класс `[[\w]...]` — FutureWarning и ноль
   срабатываний. В lookbehind подставлять класс ЦЕЛИКОМ: `(?<={W})`.
3. NBSP-вклейка через lookahead оставляла двойной пробел (консьюмить пробел в паттерне,
   а не lookahead).
4. ` - ` с двойными пробелами не схлопывался, пока схлопывание пробелов шло ПОСЛЕ тире —
   фикс: `[ \t]+-[ \t]+` прямо в regex тире.
5. Строка целиком из иероглифов после --remove оставляла висячий пробел — хвостовые
   пробелы чистятся `r"[ \t]+\n"`.
6. Чек теста должен отражать реальное ожидание: проверка `"()"` на замапленные скобки
   была неверной (скобки в тесте не смежные) — «не прошло» оказалось артефактом чека.
